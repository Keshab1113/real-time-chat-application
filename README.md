# 📡 Real-Time Chat App (Next.js + Socket.io)

A real-time chat application built using **Next.js**, **Socket.io**, and **Tailwind CSS**. This app allows users to chat instantly with messages appearing in real-time.

---

## 🚀 Features

- **Real-time messaging** using WebSockets (Socket.io)
- **Sender's messages appear on the right** (Blue)
- **Receiver's messages appear on the left** (Gray)
- **Connection status indicator** (🟢 Connected / 🔴 Disconnected)
- **Auto-scroll** to the latest message
- **Enter key to send messages**
- **Neat and responsive UI** with Tailwind CSS

---

## 🛠️ Tech Stack

- **Frontend**: Next.js (React framework)
- **Backend**: Socket.io Server (Node.js & Express)
- **UI Styling**: Tailwind CSS
- **Unique User IDs**: NanoID

## 🏗️ Installation & Setup

### 1️⃣ Clone the Repository
```sh
git clone https://github.com/your-username/chat-app.git
cd chat-app
```

### 2️⃣ Install Dependencies
```sh
npm install
```

### 3️⃣ Start the Backend Server
```sh
node server.js
```

### 4️⃣ Start the Frontend (Next.js)
```sh
npm run dev
```

### 5️⃣ Open the App
Visit **http://localhost:3000** in your browser to start chatting!
